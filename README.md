# 売上実績＆売れ筋商品比較分析ダッシュボード (analysis_rep)

単品別の売上実績データを取り込み、日商ベースでの売上実績比較および売れ筋商品のランキング推移・カテゴリ別構成比を瞬時に可視化・分析するブラウザ完結型ダッシュボードアプリケーションです。

---

## 🌟 主な特徴・機能

### 1. 直感的なデータアップロード
- **ドラッグ＆ドロップ対応**: ヘッダーの「基準データアップロード」および「比較データアップロード」エリアにファイルをドロップまたは選択するだけで即座に認識・表示。
- **データリセット機能**: ゴミ箱アイコンボタンをクリックすることで、アップロードされたデータをワンクリックで初期化。

### 2. 多角的・立体的な売上比較分析
- **エグゼクティブKPIサマリー**: 比較基準・比較対象の日商比較、対比増減率および差額をハイライト表示。
- **日商ベースの売れ筋ランキング**: 基準期間 vs 比較対象期間のTop 15商品の販売実績、構成比、順位変動を視覚的に提示。
- **部門・カテゴリ別構成比**: パレート図および円グラフによるカテゴリー別売上シフトの可視化。

### 3. モダンで快適なUI / UX
- **アイコン統一ボタン設計**: 全画面表示、テーマ切り替え、データリセットの各操作をアイコンのみで統一したスマートなヘッダーデザイン。
- **ダークモード / ライトモード対応**: ワンクリックでハイコントラストなライトテーマと洗練されたダークテーマを相互に切り替え可能（設定は自動保存）。
- **全画面表示モード**: プレゼンテーションや会議時に画面全体を活用した全画面ダッシュボード表示に対応。

### 4. 完全ローカル・オフライン完結
- 外部CDNに依存せず、主要ライブラリ（Chart.js, SheetJS）をローカルバンドル (endor/)。
- 機密データである売上情報が外部サーバーへ送信されることは一切ありません。

## 🚀 起動方法

特別な環境構築（PythonやNode.js等）は不要です。
ブラウザ（Chrome, Edge, Firefox等）で sales_analysis_report.html を開くだけで即座に動作します。
