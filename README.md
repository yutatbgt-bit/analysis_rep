# 店舗売上データ分析ツール (analysis_rep)

単品別の売上実績CSVファイルからデータを自動検出して読み込み、日付・時刻ベースで売上の比較分析を行い、レポートを自動保存するPythonツールです。

## 概要

本ツールは、[input_data/](input_data/) ディレクトリに配置された単品別売上実績CSVデータをスキャンし、**CSVデータ内の2行目に記載されている「対象期間開始日」**に基づいて古い順にソートします。
そして、選択した比較モード（実行するスクリプト）に応じて以下の項目についての比較および抽出を行います。

1. **全体売上の比較** (期間ごとの日商サマリー)
2. **売れ筋商品ランキング比較** (Top 15 - 日商ベース)
3. **売上増減の顕著な商品抽出**
4. **商品カテゴリ別の売上構成比とシフトの比較**

分析を実行すると、結果が標準出力（コンソール）へ出力されると同時に、[output_data/](output_data/) ディレクトリへレポートがマークダウンファイルとして自動的に書き出されます。

## 動作環境

- **Python**: 3.12 以上
- **パッケージ管理・実行ツール**: uv
- **主要ライブラリ**: pandas, numpy, openpyxl

## 商品カテゴリー設定ファイルについて

プロジェクトルートに配置された `config.md.xlsx`（または `config.xlsx`）からカテゴリー情報を自動で読み込みます。
- **シート名**: カテゴリー名（例: 「野菜」「刺身」「スイーツ・洋菓子」など）
- **列構成**: 「商品コード」「商品名」
- **自動分類ロジック**: CSVデータ内の商品コードで完全一致判定を行い、未一致の場合は商品名でフォールバック判定します。該当のない商品は「その他」に自動分類されます。


## セットアップ手順

本プロジェクトは `uv` を使用して依存関係を管理しています。

### 1. 仮想環境の構築と依存関係のインストール

プロジェクトのルートディレクトリで以下のコマンドを実行し、`.venv` 仮想環境の構築および依存関係のインストールを行います。

```powershell
uv sync
```

### 2. VS Codeの設定 (推奨)

VS Codeをご利用の場合、[.vscode/settings.json](.vscode/settings.json) により、Pythonの既定のインタープリタが自動的に本プロジェクトの `.venv` 内のPythonを指すように設定されています。

## 使用方法

### 1. データの配置
分析対象となるCSVファイルを [input_data/](input_data/) ディレクトリに配置します。

- **日付判定とソート**: プログラムはCSVファイルの2行目にある「対象期間開始日」を読み取り、古い順にファイルを並べ替えて処理対象を決定します。
- **同日ファイルの扱い**: 同一日の別時刻のファイルであってもエラーにはならず、ファイル名のタイムスタンプ（出力時刻）の順序に従ってソートし、比較を行います。

### 2. スクリプトの実行

実行したい比較モードに合わせて、以下のいずれかのスクリプトを実行します。

#### ① 一番古いファイルと、その次のファイルの比較
最も古い開始日のファイルと、2番目に古い開始日のファイルの1対1の比較を行います。
```powershell
uv run src/main.py
```

#### ② 一番古いファイルと、その他のファイルすべてとの比較
最も古い開始日のファイルを基準とし、それ以外のすべてのファイル（より新しい開始日）と個別に比較した結果を出力します。
```powershell
uv run src/main2.py
```

#### ③ 連続比較 (隣り合うファイル同士の比較)
ファイルを日付順に並べ、隣り合うペア（1番古い vs 2番目、2番目 vs 3番目...）で順次比較した結果を出力します。
```powershell
uv run src/main3.py
```

### 3. レポートの確認
スクリプトの実行が完了すると、[output_data/](output_data/) フォルダ内に以下のようなマークダウン形式の比較レポートファイルが自動生成されます。

- **ファイル名例**: `売上比較レポート_20260713_月_1001_vs_20260706_月_0957.md`
